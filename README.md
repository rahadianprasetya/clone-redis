# Rust Redis Clone — Learning Project

Repository ini merupakan **project latihan untuk belajar bahasa pemrograman Rust** dengan mengambil inspirasi dari project *Write a Redis Clone* dalam ebook ***Rust Projects - Write a Redis Clone*** oleh **Leonardo Giordani**.

> **Catatan:** Project ini dibuat untuk tujuan pembelajaran dan latihan Rust. Ini **bukan implementasi Redis yang sebenarnya** dan tidak ditujukan sebagai pengganti Redis.

## Tujuan

Tujuan utama project ini adalah memahami konsep-konsep Rust melalui proses membangun sebuah program yang memiliki konsep dan komponen yang menyerupai Redis secara sederhana.

Beberapa konsep Rust yang dipelajari antara lain:

* Ownership dan Borrowing
* Struct dan Enum
* Trait dan Generic
* Error Handling
* Pattern Matching
* Module dan Package
* Collection
* Networking
* TCP Server
* Concurrency
* Thread
* Async Programming
* Serialization dan Parsing
* Testing
* Penggunaan Cargo dan Crate

Project ini lebih berfokus pada **proses belajar dan memahami Rust** daripada menghasilkan Redis yang kompatibel dengan Redis asli.

## Referensi

Project ini merupakan implementasi latihan pribadi berdasarkan materi tersebut dan tidak merepresentasikan source code resmi dari buku maupun Redis.

## Disclaimer

Project ini dibuat sebagai bagian dari proses belajar Rust.

Implementasi yang terdapat di repository ini dapat berbeda dari implementasi dalam ebook maupun Redis asli, baik dari sisi:

* Struktur project
* Arsitektur
* API
* Performa
* Fitur
* Error handling
* Concurrency
* Network protocol

Karena itu, project ini sebaiknya dianggap sebagai **learning project**, bukan production-ready Redis implementation.

## Redis Clone vs Learning Project

Secara sederhana:

```text
Redis
└── Production-ready in-memory data store

Redis Clone
└── Project untuk membuat implementasi Redis

Project ini
└── Latihan belajar Rust
    └── Terinspirasi dari project "Write a Redis Clone"
```

Fokus repository ini adalah **belajar Rust dengan membuat sesuatu yang menyerupai Redis**, bukan membuat Redis yang benar-benar kompatibel dengan Redis.
